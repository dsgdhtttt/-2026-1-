这套人力资源招聘小程序系统，专为劳务中介、本地人才市场、人力资源公司打造，支持一键切换【求职者 / 企业】两种身份，打通招聘全业务闭环，多端适配，开箱部署即可运营。

### 👨‍💼 求职者端

- 首页：城市定位、职位搜索，四大岗位分类：全部职位、急招岗位、兼职招聘、红包招聘；附带招聘公告、名企推荐
- 找工作：多维度筛选，按区域、行业、薪资区间过滤岗位；岗位卡片展示薪资、地点、学历、工作年限、福利标签（五险一金、双休、补贴等）
- 个人中心：岗位推荐、消息中心、面试邀请、投递记录、岗位收藏；在线编辑简历；浏览记录：我看过谁、谁看过我，附带评论、隐私设置
- 简历详情：完整展示求职者基础信息、意向岗位、联系方式、个人能力标签，方便企业快速筛选人才

### 🏢 企业端（一键切换身份）

- 企业工作台：发布管理、消息中心、人才推荐、应聘简历、面试邀请统一管理
- 企业主页：完善公司资料、上传企业简介、公司环境图，打造企业展示主页，提升曝光
- 人才库：检索浏览求职者简历，定向邀约面试
- 面试流程管理：面试状态标签：待同意、拒绝、面试中、录用、不合适；可填写面试时间、地址、联系人、备注信息
